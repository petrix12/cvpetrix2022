# Freelancer

## Plataformas de trabajo
- [ ] 1. **Upwork (Puesto 1)**: Es el mercado más grande del mundo. Los clientes publican problemas específicos (ej: "My Laravel site is throwing a 500 error after update") y tú aplicas. Hay muchísimo volumen de micro-tareas de backend.
- [ ] 2. **Fiverr (Puesto 2)**: Aquí tú no buscas ofertas, sino que publicas tus "anuncios" (Gigs) y el cliente te compra directamente. Es perfecta para tus servicios cerrados.
- [ ] 3. **Freelancer.com (Puesto 3)**: Hay volumen, pero hay mucha guerra de precios a la baja y bots aplicando. Déjala como tercera opción en el bucle.
- [ ] 4. **Malt (Bonus España)**: Es muy fuerte en España y las empresas pagan bien, pero buscan proyectos algo más corporativos. Mantenla en el radar para cuando el bucle avance.

## servicios cerrados y específicos
### Reparaciones de Emergencia (Backend & DB)
+ "Reparar error de conexión a Base de Datos MySQL / MariaDB" (Típico fallo de credenciales, límites de conexiones o corrupción de tablas).
+ "Solucionar Error 500 / Pantalla en blanco en sitios PHP y Laravel" (Depuración rápida revisando los storage/logs/laravel.log o logs de Nginx/Apache).
+ "Corregir errores de Migraciones de Base de Datos en Laravel" (Conflictos de claves foráneas o tablas duplicadas que bloquean despliegues).

### Optimización y Rendimiento
+ "Optimizar consultas SQL lentas y añadir indexación en MySQL" (Ideal para clientes a los que se les cae la web cuando entran más de 10 personas).
+ "Configurar caché (Redis/Memcached) para acelerar Laravel" (Un cambio de configuración limpio que da resultados inmediatos).

### Entornos de Desarrollo
+ "Configurar entorno Docker / Docker Compose para desarrollo local PHP" (Crear el Dockerfile y docker-compose.yml perfecto para que otro desarrollador levante el proyecto en 2 minutos).
+ "Migrar o replicar entorno de desarrollo local a WSL (Ubuntu) en Windows" (Hacer que su flujo de trabajo vuele configurando correctamente el entorno dentro de Windows).

### Automatización & Scripts (Bash / Batch / Python)
+ "Scripts en Bash (.sh) para copias de seguridad automatizadas y rotación de logs en Linux" (El clásico script que hace un dump de la base de datos MySQL, lo comprime en un .tar.gz y lo sube de forma segura a un almacenamiento externo o AWS).
+ "Automatización de tareas rutinarias en Windows mediante archivos Batch (.bat) o PowerShell" (Scripts rápidos para mover archivos masivos, limpiar directorios temporales de servidores de forma programada o configurar variables de entorno).
+ "Scripts de sincronización y despliegue automático de código" (Pequeños scripts que automatizan el flujo de descargar cambios de Git, limpiar cachés de la aplicación, ejecutar migraciones de bases de datos y reiniciar contenedores Docker con un solo comando).
+ "Scripts híbridos para procesamiento y limpieza de datos masivos" (Unir el poder de Bash o Python para leer archivos CSV/JSON gigantescos, formatear los datos y meterlos limpios en una base de datos MySQL sin bloquear el servidor).

### Ingeniería de Datos en Excel
+ "Limpieza, depuración y formateo de datos masivos en Excel" (El típico cliente que descarga un reporte en CSV feo, desordenado, con textos rotos o filas duplicadas de su tienda online, y necesita dejarlo limpio, estructurado y listo para usar).
+ "Automatización de flujos con Power Query (Unificación de datos)" (Conectar múltiples archivos de Excel o carpetas llenas de informes mensuales para que se unifiquen en una sola tabla maestra de forma automática con un clic).
+ "Fórmulas avanzadas y resolución de errores (BUSCARV, XLOOKUP, INDEX/MATCH)" (Arreglar hojas de cálculo corporativas que devuelven errores como #N/A o #¡VALOR!, o migrar sistemas de fórmulas antiguos a lógicas más eficientes y rápidas que no congelen el ordenador).
+ "Preparación de archivos Excel para importación/exportación de bases de datos (MySQL/APIs)" (Esto une tus dos mundos: preparar el Excel con la estructura exacta, delimitadores y tipos de datos correctos para poder subirlo a un sistema web o base de datos sin fallos).

### Scraping y Extracción de Datos
+ "Extracción de datos web (Web Scraping) a formato Excel / CSV:" El cliente te da una URL (un directorio, una tienda online, un listado de empresas) y tú usas Python para extraer la información estructurada y entregársela en un Excel limpio.
+ "Automatización de descargas de archivos masivos:" Scripts para entrar a un portal, loguearse de forma automática, descargar los PDFs o facturas de cada mes y organizarlos en carpetas.
